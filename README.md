## HEALTHCARE TRACKER APP

### Summary / Goal
 - Design and Build a Healthcare Web App, Native Cross-Platform Desktop App, or Plugin for NextCloud 
 - Preferred, but not Required if other better Option(s): NextCloud Plugin 
 - Sections should Include:
    - Document Upload (Plain Text, Word, Excel, PDF, etc.)
    - Sections that a standard Personal Healthcare Tracker/Keeper would include:
        - Profile Snapshot
        - Insurance and Pharmacy Information
        - Doctor and Specialist Information
        - Family Health History
        - Surgery Records
        - Hospitalization/ER Records
        - Vision History
        - Dental History
        - Vaccination Records
        - Medications, Vitamins, and Supplements
        - Ailment History
        - Doctor's Office Visit Logs

 5. Handoff Design Task to Claude Design.
